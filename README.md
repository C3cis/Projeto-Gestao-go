#  Equipment Management System

Sistema de gestão administrativa voltado para acompanhamento, organização e controle de ativos e equipamentos.
Integrado na sua funcionalidades, áreas de trabalho de controle, manutenção, pedidos e geração de relatórios para o rastreio. 

### Arquitetura & Tecnologias

| Camada | Tecnologia | Função |
| :--- | :--- | :--- |
| **Backend** | Go / Node.js (Bun) | Regras de negócio e APIs de alta performance |
| **Frontend** | Vue.js + TypeScript | Interface dinâmica e desacoplada |
| **UI / UX** | Tailwind CSS | Design responsivo e utilitário |
| **Design Pattern** | MVC | Organização e divisão de responsabilidades |

---

###  Objetivos do Projeto
- Centralizar a administração de equipamentos em um sistema marcado por varias funcionalidades.
- Aplicar boas práticas de arquitetura MVC em ambiente Fullstack.
